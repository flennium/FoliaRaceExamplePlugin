# FoliaRace example plugin

This is a small standalone Folia plugin that uses the published FoliaRace artifact. It demonstrates the dependency and runtime pattern for a new plugin repository.

## What it demonstrates

- `compileOnly("com.foliarace:foliarace-plugin:0.1.0")` in Gradle;
- `depend: [FoliaRace]` in `plugin.yml`;
- region and global scheduler usage;
- location/block observations;
- entity observations;
- player inventory and global inventory observations;
- the async scheduler path, kept disabled by default;
- an explicit `FoliaRaceObservations` call before each demonstrated access.

The normal configuration is safe. `run-unsafe-examples: true` enables one deliberately incorrect async access so the detector and report path can be inspected. Do not enable it in production.

## Build and package consumption

This repository is ready to use as a starting point for a new Folia plugin. GitHub Packages Maven/Gradle dependency resolution requires a personal access token classic with `read:packages` for local development.

```powershell
$env:GITHUB_ACTOR = "your-github-user"
$env:GITHUB_TOKEN = "your-read-packages-token"
./gradlew build
```

The package repository and dependency are configured in `build.gradle.kts`. Do not commit the token.

The FoliaRace artifact is `compileOnly` because FoliaRace is installed as a separate server plugin. `depend: [FoliaRace]` makes the server load FoliaRace before this example. Do not shade or bundle another copy.

For local development against a FoliaRace checkout, publish the plugin to Maven Local first, then build this repository with:

```powershell
# In the FoliaRace checkout
./gradlew :foliarace-plugin:publishPluginPublicationToMavenLocal

# Back in this repository
./gradlew build -PuseMavenLocal
```

## Install on Folia

1. Build the example with `./gradlew build`.
2. Copy `build/libs/foliarace-example-plugin-1.0.0.jar` and the FoliaRace plugin JAR into the server's `plugins` directory.
3. Ensure the configured world is loaded and has a block plus an entity nearby.
4. Start Folia and check the log for location, entity, inventory, and global observation messages.
5. Review the report generated by FoliaRace.

The FoliaRace plugin must be installed separately. The example uses `compileOnly` so it does not bundle a second FoliaRace instance.
